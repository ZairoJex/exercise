## 5. 容器类型：为什么需要它们

变量可以保存单个值：

```python
category = "账号"
priority = 2
```

但真实程序通常要处理一批数据：

```text
第 1 张工单：账号问题，优先级 2
第 2 张工单：支付问题，优先级 1
第 3 张工单：账号问题，优先级 3
```

如果只用普通变量，会变成：

```python
category1 = "账号"
priority1 = 2
category2 = "支付"
priority2 = 1
category3 = "账号"
priority3 = 3
```

这种写法的问题是：

1. 工单数量一多，变量名会失控。
2. 循环无法方便地处理 `category1`、`category2`、`category3`。
3. 新增字段时要改很多地方。
4. 数据结构看不出“一张工单”这个整体概念。

所以需要容器：

```python
tickets = [
    {"id": 1, "category": "账号", "priority": 2},
    {"id": 2, "category": "支付", "priority": 1},
    {"id": 3, "category": "账号", "priority": 3},
]
```

这段代码的含义是：

- `tickets` 是一个列表。
- 列表里有 3 个元素。
- 每个元素都是一个字典。
- 每个字典表示一张工单。
- 工单字段包括 `id`、`category`、`priority`。

## 6. 四种容器的选择规则

### 6.1 `list`：有顺序、可重复、经常增删改

列表适合保存一批同类对象：

```python
categories = ["账号", "支付", "账号"]
```

特点：

- 保持插入顺序。
- 允许重复值。
- 可以追加、删除、修改。
- 可以通过索引取值。

示例：

```python
categories = ["账号", "支付", "账号"]

print(categories[0])
print(categories[1])
print(len(categories))

categories.append("物流")
print(categories)
```

输出：

```text
账号
支付
3
['账号', '支付', '账号', '物流']
```

注意：索引从 0 开始，不是从 1 开始。

### 6.2 `tuple`：有顺序、通常不修改

元组和列表很像，但元组创建后通常不修改：

```python
ticket_fields = ("id", "category", "priority")
```

适合表示固定结构、固定顺序的一组值。

示例：

```python
ticket_summary = (1, "账号", 2)

print(ticket_summary[0])
print(ticket_summary[1])
print(ticket_summary[2])
```

输出：

```text
1
账号
2
```

如果你尝试修改元组：

```python
ticket_summary[0] = 100
```

会得到 `TypeError`。这正是元组的价值：它表达“这组数据不应该被随便改”。

### 6.3 `set`：不重复、不关心顺序

集合适合去重：

```python
categories = {"账号", "支付", "账号"}
print(categories)
```

集合中不会保留重复的 `"账号"`。但集合不保证按你写入的顺序输出，所以不要依赖集合顺序。

从列表转换为集合：

```python
category_list = ["账号", "支付", "账号"]
unique_categories = set(category_list)

print(unique_categories)
```

如果需要稳定输出，可以再排序：

```python
print(sorted(unique_categories))
```

### 6.4 `dict`：用名字访问字段

字典适合表示结构化数据：

```python
ticket = {"id": 1, "category": "账号", "priority": 2}
```

读取字段：

```python
print(ticket["id"])
print(ticket["category"])
print(ticket["priority"])
```

输出：

```text
1
账号
2
```

字典中的 `"id"`、`"category"`、`"priority"` 叫键，右侧的 `1`、`"账号"`、`2` 叫值。

## 7. 字典读取：`[]` 和 `.get()` 的区别

用方括号读取：

```python
ticket = {"id": 1, "category": "账号", "priority": 2}
print(ticket["category"])
```

如果键存在，读取成功。如果键不存在：

```python
print(ticket["status"])
```

会得到 `KeyError`。

使用 `.get()`：

```python
print(ticket.get("status"))
print(ticket.get("status", "未处理"))
```

输出：

```text
None
未处理
```

`.get()` 的形式是：

```python
字典.get(键, 默认值)
```

当键存在时，返回实际值；当键不存在时，返回默认值。

今天最重要的用法是统计数量：

```python
counts = {}
category = "账号"

counts[category] = counts.get(category, 0) + 1

print(counts)
```

输出：

```text
{'账号': 1}
```

解释：

1. 一开始 `counts` 是空字典。
2. `counts.get("账号", 0)` 因为找不到 `"账号"`，返回默认值 `0`。
3. `0 + 1` 得到 `1`。
4. `counts["账号"] = 1` 把统计结果写回字典。

再统计一次 `"账号"`：

```python
counts[category] = counts.get(category, 0) + 1
print(counts)
```

这次 `counts.get("账号", 0)` 能找到已有值 `1`，所以新值变成 `2`。

## 8. 遍历工单列表

先创建数据：

```python
tickets = [
    {"id": 1, "category": "账号", "priority": 2},
    {"id": 2, "category": "支付", "priority": 1},
    {"id": 3, "category": "账号", "priority": 3},
]
```

遍历每张工单：

```python
for ticket in tickets:
    print(ticket)
```

输出：

```text
{'id': 1, 'category': '账号', 'priority': 2}
{'id': 2, 'category': '支付', 'priority': 1}
{'id': 3, 'category': '账号', 'priority': 3}
```

读取每张工单的字段：

```python
for ticket in tickets:
    print(f"工单 {ticket['id']}：{ticket['category']}，优先级 {ticket['priority']}")
```

输出：

```text
工单 1：账号，优先级 2
工单 2：支付，优先级 1
工单 3：账号，优先级 3
```

这里的 `ticket` 是循环变量。每轮循环中，`ticket` 会依次指向列表里的一个字典。

## 9. 任务一：统计每个类别的工单数量

目标输出：

```text
账号: 2
支付: 1
```

实现：

```python
category_counts = {}

for ticket in tickets:
    category = ticket["category"]
    category_counts[category] = category_counts.get(category, 0) + 1

print(category_counts)
```

输出：

```text
{'账号': 2, '支付': 1}
```

如果希望一行一行输出：

```python
for category, count in category_counts.items():
    print(f"{category}: {count}")
```

`items()` 会让你同时拿到键和值：

```python
for 键, 值 in 字典.items():
    ...
```

在这个项目中就是：

```python
for category, count in category_counts.items():
    ...
```

## 10. 任务二：输出所有不重复类别

方式一：先用空集合，再逐个加入。

```python
unique_categories = set()

for ticket in tickets:
    unique_categories.add(ticket["category"])

print(unique_categories)
```

输出可能是：

```text
{'支付', '账号'}
```

也可能是：

```text
{'账号', '支付'}
```

集合不承诺输出顺序，所以如果要稳定输出，使用：

```python
for category in sorted(unique_categories):
    print(category)
```

方式二：用集合推导式：

```python
unique_categories = {ticket["category"] for ticket in tickets}
```

这行代码的含义是：

```text
遍历 tickets 中的每个 ticket
取出 ticket["category"]
把取出的类别放入集合
重复类别自动合并
```

初学阶段可以先用方式一，等熟练后再使用集合推导式。

## 11. 任务三：按优先级排序

工单中的 `priority` 表示优先级。本教程约定：数字越小，越优先处理。

原始顺序：

```text
id=1 priority=2
id=2 priority=1
id=3 priority=3
```

排序后应该是：

```text
id=2 priority=1
id=1 priority=2
id=3 priority=3
```

使用 `sorted()`：

```python
sorted_tickets = sorted(tickets, key=lambda ticket: ticket["priority"])
```

完整输出：

```python
for ticket in sorted_tickets:
    print(f"工单 {ticket['id']}：优先级 {ticket['priority']}，类别 {ticket['category']}")
```

### 11.1 `sorted(..., key=...)` 怎么理解

`sorted()` 的基本作用是返回一个新的排序后列表：

```python
numbers = [3, 1, 2]
print(sorted(numbers))
print(numbers)
```

输出：

```text
[1, 2, 3]
[3, 1, 2]
```

原列表 `numbers` 没有被改变。

但工单是字典，Python 不知道应该按哪个字段排：

```python
{"id": 1, "category": "账号", "priority": 2}
```

所以要告诉 `sorted()`：每张工单拿哪个值作为排序依据。

```python
key=lambda ticket: ticket["priority"]
```

可以读作：

```text
对每个 ticket，取 ticket["priority"] 作为排序用的值
```

如果不想立刻学 `lambda`，也可以写成普通函数：

```python
def get_priority(ticket: dict) -> int:
    return ticket["priority"]


sorted_tickets = sorted(tickets, key=get_priority)
```

这和 `lambda` 版本效果相同。初学时，普通函数更容易调试。

### 11.2 `sorted()` 和 `.sort()` 的区别

`sorted()` 返回新列表，不修改原列表：

```python
numbers = [3, 1, 2]
new_numbers = sorted(numbers)

print(numbers)
print(new_numbers)
```

`.sort()` 会原地修改列表：

```python
numbers = [3, 1, 2]
numbers.sort()

print(numbers)
```

在今天项目里，推荐使用 `sorted()`。原因是保留原始工单顺序更利于排查问题。

## 12. 完整项目实现

在 `D:\Agent\ai-agent-road\exercises\week01\day03\day03.py` 中写入：

```python
TICKETS = [
    {"id": 1, "category": "账号", "priority": 2},
    {"id": 2, "category": "支付", "priority": 1},
    {"id": 3, "category": "账号", "priority": 3},
]


def count_by_category(tickets: list[dict]) -> dict:
    counts = {}

    for ticket in tickets:
        category = ticket["category"]
        counts[category] = counts.get(category, 0) + 1

    return counts


def get_unique_categories(tickets: list[dict]) -> set:
    categories = set()

    for ticket in tickets:
        categories.add(ticket["category"])

    return categories


def sort_by_priority(tickets: list[dict]) -> list[dict]:
    return sorted(tickets, key=lambda ticket: ticket["priority"])


def print_category_counts(counts: dict) -> None:
    print("各类别工单数量：")

    for category in sorted(counts):
        print(f"- {category}: {counts[category]}")


def print_sorted_tickets(tickets: list[dict]) -> None:
    print("按优先级排序：")

    for ticket in tickets:
        print(
            f"- 工单 {ticket['id']}: "
            f"类别={ticket['category']}, 优先级={ticket['priority']}"
        )


def print_unique_categories(categories: set) -> None:
    print("不重复类别：")

    for category in sorted(categories):
        print(f"- {category}")


def main() -> None:
    category_counts = count_by_category(TICKETS)
    sorted_tickets = sort_by_priority(TICKETS)
    unique_categories = get_unique_categories(TICKETS)

    print_category_counts(category_counts)
    print()
    print_sorted_tickets(sorted_tickets)
    print()
    print_unique_categories(unique_categories)


if __name__ == "__main__":
    main()
```

运行：

```powershell
uv run python exercises\week01\day03\day03.py
```

预期输出：

```text
各类别工单数量：
- 支付: 1
- 账号: 2

按优先级排序：
- 工单 2: 类别=支付, 优先级=1
- 工单 1: 类别=账号, 优先级=2
- 工单 3: 类别=账号, 优先级=3

不重复类别：
- 支付
- 账号
```

说明：中文字符串排序时，`支付` 和 `账号` 的先后由 Python 的 Unicode 顺序决定。这里使用 `sorted()` 是为了输出稳定，而不是为了表达业务顺序。

## 13. 逐段理解完整代码

### 13.1 为什么常量名写成 `TICKETS`

```python
TICKETS = [...]
```

全大写通常表示“这个值作为配置或固定样例数据使用，不建议在程序运行中随便改”。这不是 Python 强制规则，而是程序员之间的约定。

### 13.2 为什么函数接收 `tickets`

不要在函数里直接依赖全局变量：

```python
def count_by_category() -> dict:
    for ticket in TICKETS:
        ...
```

这种写法能跑，但复用性差。更好的写法是：

```python
def count_by_category(tickets: list[dict]) -> dict:
    ...
```

这样将来换一批工单数据，函数仍然可用。

### 13.3 `counts.get(category, 0) + 1` 是今天重点

```python
counts[category] = counts.get(category, 0) + 1
```

如果类别第一次出现：

```text
counts.get(category, 0) -> 0
0 + 1 -> 1
```

如果类别已经出现过：

```text
counts.get(category, 0) -> 已有数量
已有数量 + 1 -> 新数量
```

这行代码避免了下面这种重复写法：

```python
if category in counts:
    counts[category] += 1
else:
    counts[category] = 1
```

两种写法都正确，但 `.get()` 更短，也很常见。

### 13.4 为什么排序函数返回新列表

```python
def sort_by_priority(tickets: list[dict]) -> list[dict]:
    return sorted(tickets, key=lambda ticket: ticket["priority"])
```

这个函数不会改变传入的 `tickets`。这点很重要，因为真实业务里经常同时需要：

- 原始创建顺序。
- 按优先级排序后的处理顺序。
- 按类别过滤后的列表。

保留原数据可以减少很多调试成本。

## 14. 给程序加自检

初学阶段可以用 `assert` 做最小自检。把下面代码放在 `main()` 前面：

```python
def run_checks() -> None:
    counts = count_by_category(TICKETS)
    assert counts == {"账号": 2, "支付": 1}

    sorted_tickets = sort_by_priority(TICKETS)
    assert [ticket["id"] for ticket in sorted_tickets] == [2, 1, 3]

    unique_categories = get_unique_categories(TICKETS)
    assert unique_categories == {"账号", "支付"}

    assert [ticket["id"] for ticket in TICKETS] == [1, 2, 3]
```

再修改 `main()`：

```python
def main() -> None:
    run_checks()

    category_counts = count_by_category(TICKETS)
    sorted_tickets = sort_by_priority(TICKETS)
    unique_categories = get_unique_categories(TICKETS)

    print_category_counts(category_counts)
    print()
    print_sorted_tickets(sorted_tickets)
    print()
    print_unique_categories(unique_categories)
```

如果所有断言通过，程序正常输出。如果某个断言失败，Python 会抛出 `AssertionError`。

这组自检覆盖了四件事：

1. 类别统计正确。
2. 排序顺序正确。
3. 去重类别正确。
4. `sort_by_priority()` 没有破坏原始列表顺序。

## 15. 常见错误

### 15.1 把列表和字典混在一起

错误：

```python
print(tickets["category"])
```

原因：`tickets` 是列表，不是单张工单字典。列表不能用 `"category"` 作为索引。

正确：

```python
for ticket in tickets:
    print(ticket["category"])
```

### 15.2 忘记把统计结果写回字典

错误：

```python
counts.get(category, 0) + 1
```

这行代码只计算了新数字，但没有保存。

正确：

```python
counts[category] = counts.get(category, 0) + 1
```

### 15.3 误以为集合有固定顺序

不要写依赖集合顺序的判断：

```python
print(set(["账号", "支付", "账号"]))
```

输出顺序不适合作为业务逻辑依据。需要稳定展示时：

```python
print(sorted(set(["账号", "支付", "账号"])))
```

### 15.4 排序时把 `key` 写成固定值

错误：

```python
sorted_tickets = sorted(tickets, key="priority")
```

`key` 需要的是一个函数，用来告诉 Python 如何从每个元素里取排序依据。

正确：

```python
sorted_tickets = sorted(tickets, key=lambda ticket: ticket["priority"])
```

或：

```python
def get_priority(ticket: dict) -> int:
    return ticket["priority"]


sorted_tickets = sorted(tickets, key=get_priority)
```

### 15.5 把 `print()` 当作函数返回值

错误：

```python
def count_by_category(tickets: list[dict]) -> dict:
    counts = {}
    ...
    print(counts)
```

这个函数只打印，不返回，后续代码无法复用统计结果。

正确：

```python
def count_by_category(tickets: list[dict]) -> dict:
    counts = {}
    ...
    return counts
```

展示输出交给单独的打印函数。

## 19. 练习参考答案（完成后再核对）

### 19.1 基础练习：选择合适容器

1. `list`：需要保存多张工单，并保留创建时间顺序。
2. `dict`：一张工单有多个命名字段。
3. `set`：只关心类别是否出现过，不保留重复值。
4. `tuple`：字段名固定，通常不需要修改。
5. `dict`：类别作为键，数量作为值。

### 19.2 基础练习：统计状态数量

```python
tickets = [
    {"id": 1, "status": "open"},
    {"id": 2, "status": "closed"},
    {"id": 3, "status": "open"},
    {"id": 4, "status": "pending"},
]

status_counts = {}

for ticket in tickets:
    status = ticket["status"]
    status_counts[status] = status_counts.get(status, 0) + 1

print(status_counts)
```

输出：

```text
{'open': 2, 'closed': 1, 'pending': 1}
```

### 19.3 基础练习：提取唯一优先级

```python
tickets = [
    {"id": 1, "priority": 2},
    {"id": 2, "priority": 1},
    {"id": 3, "priority": 2},
    {"id": 4, "priority": 3},

priorities = set()

for ticket in tickets:
    priorities.add(ticket["priority"])

for priority in sorted(priorities):
```

```python
priorities = {ticket["priority"] for ticket in tickets}
```

### 19.6 挑战练习：同时按类别和优先级排序

```python
tickets = [
    {"id": 1, "category": "账号", "priority": 2},
    {"id": 2, "category": "支付", "priority": 1},
    {"id": 3, "category": "账号", "priority": 3},
    {"id": 4, "category": "支付", "priority": 2},
]

sorted_tickets = sorted(
    tickets,
    key=lambda ticket: (ticket["category"], ticket["priority"]),
)

for ticket in sorted_tickets:
    print(ticket)
```

`key` 返回元组时，Python 会先比较元组第一个元素；第一个元素相同，再比较第二个元素。

可能输出：

```text
{'id': 2, 'category': '支付', 'priority': 1}
{'id': 4, 'category': '支付', 'priority': 2}
{'id': 1, 'category': '账号', 'priority': 2}
{'id': 3, 'category': '账号', 'priority': 3}
```

中文类别的整体先后由 Unicode 顺序决定；同一类别内部会按 `priority` 从小到大排列。

### 19.7 挑战练习：校验工单字段

```python
def validate_ticket(ticket: dict) -> bool:
    required_fields = ("id", "category", "priority")

    for field in required_fields:
        if field not in ticket:
            return False

    if not isinstance(ticket["id"], int):
        return False

    if not isinstance(ticket["category"], str):
        return False

    if ticket["category"] == "":
        return False

    if not isinstance(ticket["priority"], int):
        return False

    if ticket["priority"] < 1:
        return False

    return True


test_tickets = [
    {"id": 1, "category": "账号", "priority": 2},
    {"id": "1", "category": "账号", "priority": 2},
    {"id": 2, "category": "", "priority": 1},
    {"id": 3, "category": "支付", "priority": 0},
    {"id": 4, "priority": 1},
]

for ticket in test_tickets:
    print(validate_ticket(ticket))
```

输出：

```text
True
False
False
False
False
```
